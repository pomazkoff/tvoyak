# Банк ×5 — генерация и ревью

Скрипты, которыми собраны миграции `20261031050000_bank_x5*.sql`. Пути внутри
указывают на рабочую папку генерации; ключ OpenRouter берётся из окружения
(`OPENROUTER_API_KEY_NEW`), в репозитории секретов нет.

- `textpipe.py`: текстовые вопросы и вопросы мозгового штурма. Генератор пишет кандидатов, потом их проверяют локально (утечка ответа, дубли по триграммам и ответу), а затем три LLM-ревьюера (факты, мейнстрим, сложность, дубли, утечка, варианты ответа).
- `musicpipe.py`: музыка, только превью iTunes, с той же схемой ревью.
- `videopipe.py` + `vkfill.py`: трейлеры. Ролик ищем на YouTube (yt-dlp, проверка oEmbed), копию на VK находят `scripts/vk-video/find.mjs` и `check.mjs`.
- `emojipipe.py`: эмодзи-шифр и «Найди лишнее» (проверяем, что эмодзи есть в Twemoji).
- `rebusgen.py` + `rebusreview.py`: ребусы детерминированно собираются из словаря `REBUS_EMOJI`, LLM отсеивает слова.
- `logocand.py` + `logosearch.py`: логотипы-знаки без надписей с Commons, только со свободной лицензией. Отбирали вручную по контактным листам.
- `build.py` + `mig.py`: сборка SQL. Повторно прогоняются `findAnswerLeaks` и `pictureProblems`.
